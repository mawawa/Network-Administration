Unix File and Directory and permissions

In unix there are three access permission bits:
  • Owner
  • group
  • Other

File Permissions

There are also three kinds of permissions for files and they are
  • read
  • write
  • execute
Usually the ececute is reserved for administrations

Directory Permission

there are also directory permissions they are also that same as file permission although they have different characteristics.
read
This allow a compnet to be able to read a file
Write
this allow a componetn to create, edit or delete fiels in a directory
Excecute
This allows a component to open and change contents of a directory

Example for file permission

drwx--xr--
the above permission mean that we are working on a directory while the order is owner, group, ,other
the permission can also be defined in form of number for example the command ,chmod 777
this is a full-access for all the three types of components. that is owners, groups and others.
